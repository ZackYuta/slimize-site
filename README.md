# slimize-site

iOSアプリ「Slimize」の公開ページ（紹介・使い方・場面別ガイド・FAQ・更新情報・お問い合わせ・プライバシーポリシー等）です。GitHub Pages で公開しています。

- トップ: https://zackyuta.github.io/slimize-site/
- プライバシーポリシー: https://zackyuta.github.io/slimize-site/privacy/

このリポジトリの内容は、開発用リポジトリから自動で同期されます。ここを直接編集しないでください（次の同期で上書きされます）。

## 画像について

- `assets/badge-appstore-ja.svg` は Apple 公式の「App Store からダウンロード」バッジ（日本語・黒）です。改変せず、そのまま使います。
- `assets/icon-*.png`・`apple-touch-icon.png`・`favicon-32.png` は、アプリのアイコン（`AppIcon.appiconset/icon2.png`）から書き出したものです。
